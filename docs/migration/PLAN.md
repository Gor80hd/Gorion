# План переноса Gorion с Flutter на нативные приложения

Статус: в работе. Начат 2026-11-11. Последнее обновление: 2026-11-12.
Ветка-источник: `refactor/core-cleanup` (Flutter, ~39 тыс. строк Dart, 60 тестовых файлов).

## Почему

Flutter рисует интерфейс сам. На macOS настоящий Liquid Glass приходится
подкладывать нативными `NSView` под прозрачный Flutter-слой и синхронизировать
их геометрию через канал (`macos/Runner/MainFlutterWindow.swift`,
`lib/core/window/window_surfaces.dart`). Стекло не преломляет Flutter-контент,
системные контролы недоступны, а каждое улучшение интерфейса упирается в мост.
На Windows та же история с акрилом. Отсюда решение: нативный интерфейс на каждой
платформе и одно общее ядро.

## Целевая архитектура

```
core/                      Cargo workspace — вся логика, одна на обе платформы
  crates/gorion-core       профили, разбор ссылок, сборка конфига sing-box,
                           автовыбор, замеры, раздельное туннелирование,
                           настройки, жизненный цикл runtime, Clash API
  crates/gorion-platform   системный прокси, процессы, watchdog — cfg по ОС
  crates/gorion-helper     привилегированный помощник (launchd / служба Windows)
  crates/gorion-ffi        UniFFI-привязки для Swift
apps/
  macos/                   SwiftUI-приложение, Liquid Glass, macOS 26+
    Gorion.xcodeproj
    Packages/GorionDesign  токены (генерируются), пружины, компоненты
    Packages/GorionKit     Swift-обёртка над ядром (XCFramework + биндинги)
  windows/                 Rust-приложение, акрил, Windows 11
design/
  tokens.json              единственный источник токенов дизайна
docs/
  migration/               этот план и таблица паритета
  adr/                     принятые решения
lib/, macos/, windows/ …   Flutter — живёт до этапа 6, только исправления
```

Решения и альтернативы: [ADR-0001](../adr/0001-shared-rust-core.md) (общее ядро на Rust),
[ADR-0002](../adr/0002-macos-swiftui-liquid-glass.md) (SwiftUI + Liquid Glass),
[ADR-0003](../adr/0003-windows-ui-stack.md) (стек интерфейса Windows — через спайк),
[ADR-0004](../adr/0004-physical-motion.md) (физическая модель движения).

## Принципы переноса

1. **Паритет до улучшений.** Сначала новое приложение делает всё, что делает
   Flutter-версия, и не хуже. Улучшения дизайна идут после паритета или
   явно помечаются в [parity.md](parity.md) как «меняем».
2. **Поведение фиксируется до переписывания.** Для каждой подсистемы ядра
   Flutter-версия выгружает золотые фикстуры (вход → выход), и Rust-реализация
   обязана их воспроизвести. Так перенос не теряет годы исправлений из
   [runtime-audit.md](../runtime-audit.md).
3. **Ядро не знает об интерфейсе.** Никаких строк для пользователя в `gorion-core`:
   ядро отдаёт коды и данные, тексты живут в приложениях.
4. **Один источник дизайна.** Цвета, отступы, скругления, шрифты и пружины —
   только из `design/tokens.json`. Значения в коде вручную не пишутся.
5. **Flutter заморожен.** В `lib/` только исправления критичных ошибок до этапа 6.
6. **Данные пользователя сохраняются.** Новое приложение использует тот же
   bundle id `app.gorion.client` и читает существующие JSON-файлы настроек и
   подписок из Application Support (форматы фиксируются фикстурами).

### Этап 1б — Свой движок подключения (`gorion-engine`, ADR-0005)

Каждый протокол закрывается сквозной проверкой против сервера sing-box на
стенде; до этого его серверы подключаются через sing-box.

- [x] Shadowsocks AEAD (aes-128-gcm, aes-256-gcm, chacha20-ietf-poly1305), direct, локальный вход SOCKS5/HTTP — совместимость с сервером sing-box проверена тестом (`GORION_SINGBOX`) и вживую через интернет; скорость наравне с клиентом sing-box, память 3,5 МБ против 34 МБ
- [ ] Движок в приложении: серверы с готовыми протоколами — через `gorion-engine`, остальные — через sing-box
- [ ] Shadowsocks 2022, Trojan (TLS)
- [ ] VLESS (TCP/TLS), транспорты ws, grpc, httpupgrade
- [ ] Маскировка TLS под Chrome, REALITY, Vision
- [ ] Hysteria2, TUIC (QUIC), AnyTLS, VMess
- [ ] UDP через прокси
- [ ] TUN: устройство, свой стек TCP/IP, DNS, раздельное туннелирование
- [x] Системный VPN: помощник launchd (выбор владельца, ADR-0005) — сделан на sing-box, свой TUN-стек позже
- [ ] sing-box убран из сборки

## Журнал

- **2026-11-12.** Первый рабочий срез на macOS: ядро на Rust (разбор, хранилище,
  конфиг, runtime, системный прокси, проверки, движок) → UniFFI → SwiftUI.
  Проверено вживую на тестовом стенде (локальный ss-сервер и подписка из 6
  серверов, режим «Только приложения»): добавление подписки, задержки,
  подключение с проверкой, смена сервера на лету, трафик, отключение, выход
  при подключении. Системный прокси основной сети не трогался. Скриншоты —
  [screenshots/](screenshots/).
- **2026-11-12.** Дизайн как во Flutter: два стеклянных островка, планета из
  точек с маршрутом, герой и плашка подключения, IP и страна выхода в ядре.
  Экран был заблокирован, поэтому проверено снимками окна изнутри отладочной
  сборки (`GORION_SNAPSHOT`): вёрстка и планета в обеих темах, подключение.
  Системное стекло такие снимки не показывают — скриншоты в `screenshots/`
  пока старого дизайна.
- **2026-11-12.** Проверено вживую после разблокировки экрана: стекло и
  зазор в обеих темах, бросок планеты, наведение с подсказкой, подключение в
  ручном режиме (сканирование, «Подключение защищено», дуга маршрута
  Германия → Турция, таймер сессии, трафик), отключение. Нагрузка
  отладочной сборки — около 26–29% при видимом окне, 0% при скрытом.
  Исправлено: подсказка страны облегает текст, вместо кода страны —
  русское название. Не проверены: щелчок по стране, подсветка из списка,
  «Уменьшить движение», VoiceOver.
- **2026-11-12.** Владелец выбрал свой движок на Rust вместо sing-box
  (ADR-0005). Первый срез — крейт `gorion-engine`: локальный вход
  SOCKS5/HTTP, прямое подключение, Shadowsocks AEAD на своём коде. Сервер
  sing-box принимает наш клиент на всех трёх шифрах; HTTPS через движок
  работает. Найдено и учтено: sing-box рвёт подключение целиком на FIN от
  клиента, поэтому клиент не полузакрывает поток, а ждёт ответ с паузой
  2 с (как Xray). Кнопки окна перенесены внутрь бокового островка.

- **2026-11-12.** Владелец выбрал «Помощник с паролем» для системного VPN
  (ADR-0005, вариант Г). Новый крейт `gorion-helper`: служба launchd,
  строки JSON через Unix-сокет только для администраторов, соединение-аренда
  (приложение пропало — ядро сразу остановлено). С главного экрана убран
  переключатель «Приложения / Вручную»: по умолчанию VPN для всего
  компьютера, без помощника — карточка «Ещё один шаг» и установка одним
  паролем. Сквозные тесты помощника без root и без TUN зелёные; настоящая
  установка не проверялась — пароль вводит только владелец.
