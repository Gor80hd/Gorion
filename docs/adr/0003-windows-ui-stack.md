# ADR-0003. Windows: стек интерфейса на Rust с акрилом

Статус: **открыто** — решается спайком на этапе 5 · 2026-11-11

## Требования

1. Системный акрил окна (`DwmSetWindowAttribute` + `DWMWA_SYSTEMBACKDROP_TYPE`,
   Windows 11 22H2+) и полупрозрачные островки поверх него.
2. Внешний вид и движение как на macOS: те же компоненты, те же пружины,
   прерываемые анимации с сохранением скорости, 60–144 Гц без рывков.
3. Качественный текст (DirectWrite, ClearType/grayscale), ввод на любом языке (IME).
4. Доступность: UI Automation (экранный диктор), навигация с клавиатуры.
5. Трей, своя строка заголовка с привязкой к Snap Layouts.
6. Разумный размер и время старта; сборка без экзотики.

## Кандидаты для спайка

| Кандидат | Что проверить в первую очередь |
| --- | --- |
| Slint | прозрачность окна под акрилом, свои пружины через таймер, доступность |
| GPUI (фреймворк Zed) | стабильность API, доступность (UIA), акрил |
| windows-rs + Windows.UI.Composition + DirectWrite | объём работы на вёрстку и текст; плюс — системные пружины `NaturalMotion` и акрил композитора |
| windows-rs + WinUI 3 | реальность использования из Rust, сходство с macOS-дизайном |

## Что сейчас используют современные Windows-приложения

- **WinUI 3 (Windows App SDK)** на C# или C++ — родной стек Windows 11: системный
  акрил и Mica, анимации композитора с пружинами (`NaturalMotion`), UI Automation,
  IME. На нём сделаны новые системные приложения.
- **WebView2 / Electron / Tauri** — веб-интерфейс в окне; гибкий дизайн, но не нативно.
- **Чистый Rust** (Slint, GPUI, egui) — моложе, меньше системной интеграции.

Текущий наклон: **WinUI 3 на C#** поверх того же Rust-ядра (через
`uniffi-bindgen-cs` или C ABI). Логика всё равно одна — на C# только экраны.
Чистый Rust (Slint) — запасной вариант, если важнее один язык. Спайк решает.

## Метод

Один экран-эталон (боковой островок со списком серверов + кнопка подключения
+ переключатель) на каждом кандидате, ≤ 1 недели в сумме. Сравнить по
требованиям выше, видео прерываемой анимации, проверка экранным диктором.
Результат записать сюда и перевести статус в «принято».
