# DESIGN.md — дизайн-система Gorion

Как Gorion выглядит, двигается и разговаривает с человеком — на macOS и Windows.
Числа здесь — пояснение; источник значений — [`design/tokens.json`](design/tokens.json).
Разночтение решается в пользу tokens.json, а этот файл исправляется.

## 1. Главное

**Gorion должен быть понятен человеку, который впервые видит VPN.** Он
открывает окно, нажимает одну кнопку — и всё работает. Всё остальное — для
тех, кто захочет копнуть глубже.

Пять правил, которые проверяются на каждом экране:

1. **Одно главное действие.** Кнопка «Подключить» видна всегда и всегда
   выглядит главной. Ничто не спорит с ней за внимание.
2. **Состояние видно с первого взгляда.** Подключено или нет, через какую
   страну, работает ли интернет. Состояние передаётся словом, значком и
   цветом одновременно — никогда только цветом.
3. **Нет тупиков.** У каждого экрана и каждой ошибки есть понятный следующий
   шаг с кнопкой. Пустой список объясняет, что сделать первым.
4. **Ничего не надо настраивать, чтобы начать.** Умолчания работают:
   автовыбор сервера включён, режим подключения не требует пароля администратора.
5. **Всё физическое.** Элементы имеют массу: разгоняются, тормозят, отвечают
   на прерывание продолжением движения, а не рывком (раздел 6).

## 2. Платформы

Один дизайн, два материала. Расположение, компоненты, тексты, движение —
одинаковые. Различаются материал, шрифт, строка заголовка и скругления.

| | macOS 26+ | Windows 11 22H2+ |
| --- | --- | --- |
| Материал | Liquid Glass (`glassEffect`) | системный акрил окна + полупрозрачные островки |
| Шрифт | SF Pro, текст 13 pt | Segoe UI Variable, текст 14 epx |
| Заголовок окна | «светофор» внутри бокового островка | полоса 40 epx, кнопки окна справа, Snap Layouts |
| Скругления остров/карточка/контрол | 22 / 14 / 10 | 16 / 12 / 8 (подбирается) |
| Меню и поповеры | системные, стеклянные | свои, `overlayFill`, тот же вид, что на macOS |
| Значок статуса | строка меню (`MenuBarExtra`) | трей |
| Сочетания клавиш | ⌘ | Ctrl |

Если системный компонент macOS делает то же, что наш, — берём системный
(меню, поповер, поле поиска, переключатель в настройках). На Windows рисуем его
двойника по той же спецификации.

## 3. Компоновка

Окно собирается из **островков** — крупных панелей с зазором между ними.

```
┌──────────────────────────────────────────────────────────┐
│ ┌──────────────┐ ┌─────────────────────────────────────┐ │
│ │ ● ● ●        │ │                                     │ │
│ │ Серверы ⚙︎    │ │            планета                  │ │
│ │ ──────────── │ │                                     │ │
│ │ 🇳🇱 Нидерланды│ │                                     │ │
│ │   сервер  42 │ │   ┌─────────────────────────────┐   │ │
│ │ 🇩🇪 Германия  │ │   │ ● Подключено · 🇳🇱 · 42 мс  │   │ │
│ │   сервер  57 │ │   │        [ Отключить ]        │   │ │
│ │              │ │   └─────────────────────────────┘   │ │
│ └──────────────┘ └─────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
   боковой островок         основной островок
```

- Зазор между островками и поля окна — `spacing.islandGap` (8).
- Ширина бокового островка — 36 % окна, от 220 до 320.
- Окно: по умолчанию 1280×800, минимум 940×600.
- Боковой островок показывает либо серверы, либо разделы настроек; переключение
  — пружина `heavy`, содержимое сменяется, островок остаётся на месте.
- Сетка 4: все отступы кратны 4. Внутренние отступы островка — 16, карточки — 12.
- Вложенные скругления концентричны: `inner = max(control, outer − inset)`.
  На macOS используйте `ConcentricRectangle` / концентрические углы контейнера.

## 4. Материал и слои

Три слоя, снизу вверх:

1. **Окно** — системный материал (стекло / акрил).
2. **Островки** — навигация и контент. На macOS — `.glassEffect` внутри одного
   `GlassEffectContainer`, чтобы островки сливались и морфили вместе.
3. **Плавающие элементы** — плашка подключения над планетой, меню, тосты.
   На macOS — стекло `.interactive()`, оно по-настоящему преломляет планету.

Правила:

- **Стекло не кладётся на стекло.** Внутри стеклянного островка карточки
  — это `cardFill`, а не ещё одно стекло.
- **Поверхности нейтральные, цвет несут только акценты.** Цветная подложка на
  полупрозрачном окне выглядит грязно. Акцент — у главной кнопки, выбранного
  элемента, индикаторов.
- На macOS заливки из `material.glass` поверх системного стекла **не**
  рисуются — они гасят стекло. Это запасной вариант для «Снизить прозрачность».
- «Снизить прозрачность» / «Повысить контраст»: материалы становятся
  непрозрачными (`windowFallback`, `surface`), обводки — плотнее.

## 5. Цвет и текст

Значения — `tokens.json` → `color`. Смысл:

| Токен | Значение |
| --- | --- |
| `brand.accent` | главное действие, выбранное, «подключено». На тёмной теме ярко-мятный, на светлой — тёмно-зелёный |
| `status.success / warning / danger / info` | только для состояний, не для украшения |
| `text.primary / muted / subtle` | основной текст / пояснение / третьестепенное |
| пинг | < 100 мс — success, < 300 мс — warning, иначе danger, нет данных — `ping.unknown` |

- Контраст текста ≥ 4.5:1 на реальном фоне (стекло над планетой — худший
  случай, проверяйте на нём). Крупный текст ≥ 3:1.
- Числа (пинг, скорость, время сессии) — моноширинные цифры, чтобы не прыгали.
- Шкала текста — `typography.scale`. На экране не больше трёх размеров.
- Регистр как в предложении: «Добавить подписку», не «Добавить Подписку».

## 6. Движение

Каждый элемент — физическое тело. У движения три фазы, и все три обязательны.

### 6.1 Стартовая скорость

Движение начинается с той скорости, которая уже есть:

| Источник (по приоритету) | Начальная скорость |
| --- | --- |
| Жест отпущен (перетаскивание, бросок, прокрутка) | скорость пальца/мыши в момент отпускания |
| Прерывание идущей анимации новой целью | текущая скорость элемента — **не ноль** |
| Дискретное действие (щелчок, клавиша) | ноль; разгон даёт пружина |

Элемент, который летел вправо и получил цель слева, сначала тормозит, затем
разворачивается — без рывка и телепорта.

### 6.2 Разгон

Разгон создаёт сила пружины, а не кривая. Чем крупнее элемент, тем он
«тяжелее» — дольше `response`, меньше отскок:

| Масса | Что двигается | Пружины |
| --- | --- | --- |
| Лёгкое | кнопка, переключатель, бегунок, значок, подсветка | `press`, `release`, `hover`, `snappy` |
| Среднее | строка списка, карточка, меню, тост, поповер | `snappy`, `bouncy`, `smooth` |
| Тяжёлое | островок, лист, смена страницы, окно, фокус планеты | `heavy` |

| Пружина | response, с | bounce | Где |
| --- | --- | --- | --- |
| `press` | 0.16 | 0 | нажатие: проседание и затемнение |
| `release` | 0.34 | 0.38 | отпускание лёгких контролов |
| `hover` | 0.20 | 0 | наведение, фокус клавиатуры |
| `snappy` | 0.32 | 0.20 | бегунки, индикатор выбора, перестановка |
| `smooth` | 0.45 | 0 | появление контента, прозрачность, цвет, размеры |
| `bouncy` | 0.42 | 0.28 | меню, поповеры, тосты, морфинг стекла |
| `heavy` | 0.55 | 0.08 | островки, листы, страницы, планета |

Прозрачность и цвет **никогда** не перелетают: для них bounce = 0
(перелёт прозрачности за 1 — ошибка).

### 6.3 Инерция

- **Перелёт** — лёгкие элементы слегка проскакивают цель и возвращаются
  (`bounce`). Тяжёлые почти не проскакивают.
- **Свободный полёт** — после броска (планета, прокрутка, ползунок) скорость
  затухает: `v(t) = v₀ · rateᵗ` (t в мс), `rate = 0.998` (обычно) или `0.99`
  (быстро). Точка остановки предсказуема: `x∞ = x₀ + v₀·τ`, `τ = −1/ln(rate)`
  (≈ 500 мс для 0.998).
- **Решение по предсказанной точке.** Куда «упадёт» переключатель, лист или
  карточка при отпускании, решает `x∞`, а не текущее положение: лёгкий бросок
  в сторону срабатывает даже с середины пути.
- **Точки притяжения.** После свободного полёта элемент доводится пружиной к
  ближайшей допустимой точке (страна на планете, деление ползунка) — с текущей
  скоростью, без остановки.
- **Резинка** за границей: `offset = (1 − 1/(x·c/d + 1)) · d`, `c = 0.55`,
  `d` — размер области. Отпустил — пружина `snappy` возвращает на место.

### 6.4 Обязательные свойства

- **Всё прерываемо.** Ввод никогда не ждёт конца анимации; элементы не
  блокируются «пока анимируется».
- **Отклик в пределах кадра.** Нажатие начинает `press` сразу, без задержки.
- Анимируются трансформация и прозрачность; перерасчёт вёрстки больших списков
  не анимируется.
- 120 Гц на ProMotion, 60–144 Гц на Windows — без пропуска кадров.
- **«Уменьшить движение»**: перемещения и масштаб → смена прозрачности на
  `smooth`, bounce = 0, автовращение планеты выключено. Обратная связь на
  нажатие остаётся (затемнение вместо масштаба).

### 6.5 Реализация

**macOS (SwiftUI).** Токен → `Spring(duration: response, bounce: bounce)`.
Пружинные анимации SwiftUI сами сохраняют скорость при смене цели.
Скорость жеста передаётся так:
`withAnimation(.interpolatingSpring(spring, initialVelocity: v / (target − current)))` —
скорость нормирована на оставшееся расстояние. Для свободного полёта и
резинки — свои типы в `GorionDesign` (`Momentum`, `RubberBand`). Готовых
кривых `.easeInOut`, `.linear` в интерфейсе нет.

**Windows (Rust).** Свой решатель в модуле движения: аналитическое решение
затухающего осциллятора (недо-, критическое и передемпфирование) по формулам
`stiffness = (2π/response)²`, `damping = 4π(1 − bounce)/response`, `mass = 1`.
Смена цели сохраняет `x` и `v`. Тик — от vsync композитора. Модуль покрыт
тестами, сверяющими траектории с эталоном (тот же расчёт, что в
`lib/core/motion/spring_motion.dart` в коммите `166ab89`).

### 6.6 Типовые движения

| Элемент | Движение |
| --- | --- |
| Кнопка | нажатие: масштаб 0.96 на `press`; отпускание: 1.0 на `release` с накопленной скоростью |
| Мелкий контрол | то же, масштаб 0.94 |
| Карточка / строка | нажатие 0.985; наведение — подсветка на `hover` |
| Переключатель | бегунок тянется за мышью; отпускание — сторона по `x∞`; `snappy`; на краях резинка |
| Ползунок | бегунок следует за курсором 1:1; деления притягивают на `snappy` |
| Индикатор выбора (сегменты, список) | перетекает к новому элементу на `snappy`, растягиваясь по скорости |
| Меню / поповер | вырастает из источника (масштаб 0.92 → 1 + прозрачность) на `bouncy`; закрытие на `smooth` |
| Тост | въезжает снизу на `bouncy`; смахивается жестом с инерцией; время показа 2.6 с + 0.18 с на слово, не больше 7 с; при наведении не исчезает |
| Подсказка | задержка 520 мс, появление на `smooth` |
| Боковой островок: серверы ↔ настройки | содержимое сменяется на `heavy` со сдвигом по направлению навигации |
| Кнопка подключения | смена состояния — морфинг формы и цвета на `bouncy`; во время подключения — дыхание (масштаб 1 ↔ 1.02 на `smooth`), не вращение спиннера |
| Планета | вращение мышью 1:1; бросок — свободный полёт; выбор страны — фокус на `heavy` |
| Пинг, скорость | смена числа — прокрутка цифр на `snappy` |

## 7. Компоненты

Каждый компонент описан один раз и реализуется одинаково на обеих платформах.
Новые компоненты добавляются сюда до кода.

| Компонент | Варианты | Правила |
| --- | --- | --- |
| Кнопка | главная (акцент), обычная, тихая, опасная; высота 28 / 32 / 40 | одна главная на экран; подпись — глагол |
| Кнопка подключения | отключено / подключение / подключено / ошибка | самый крупный интерактивный элемент экрана |
| Переключатель | — | только для мгновенно применяемых настроек |
| Ползунок | с делениями / плавный | рядом всегда текущее значение словами |
| Сегменты | 2–4 варианта | для взаимоисключающих режимов |
| Строка настроек | заголовок, пояснение, контрол справа | пояснение — что изменится для человека |
| Карточка | группа строк | `cardFill`, обводка `cardStroke`, без стекла |
| Строка сервера | флаг, имя, пинг, избранное | вся строка нажимается; действия — в меню «…» |
| Группа страны | флаг, страна, число серверов, лучший пинг | сворачивается |
| Тег | «Тест», «Авто» | маленький, приглушённый, не кнопка |
| Поле ввода | однострочное, поиск | вставка из буфера подсказывается автоматически |
| Меню | — | на macOS системное |
| Тост | информация / успех / ошибка, с действием | действие «Вернуть» вместо диалогов подтверждения |
| Диалог | — | только для необратимого (сброс всех настроек) и ввода данных |
| Пустое состояние | значок, одна фраза, одна кнопка | объясняет первый шаг |

Размер зоны нажатия — не меньше `layout.minHitTarget` (28 pt macOS / 32 epx
Windows), даже если элемент визуально меньше.

## 8. Тексты

Пишем как человек человеку. Технические слова — только в разделе
«Протоколы» и в «Подробнее».

| Не так | А так |
| --- | --- |
| TUN | «Весь компьютер» — весь трафик через VPN, даже программ, которые игнорируют прокси |
| System proxy | «Приложения» — браузеры и программы, которые используют системный прокси |
| Local proxy / mixed inbound | «Вручную» — Gorion открывает локальный прокси, программы настраиваете сами |
| Outbound, тег сервера | сервер, имя сервера |
| `connection refused`, стек ошибки | «Сервер не отвечает. Попробуйте другой — или включите автовыбор.» + [Выбрать другой] |
| Вы уверены, что хотите удалить? | удалить сразу + тост «Подписка удалена» [Вернуть] |

- Ошибка = что случилось + что делать + кнопка. Технические детали — под «Подробнее».
- Подписи кнопок — глаголы: «Подключить», «Добавить подписку», «Проверить».
- Без восклицательных знаков, без «Упс», без вины пользователя.
- Числа с единицами через неразрывный пробел: «42 мс», «1,2 МБ/с».
- Названия стран — по-русски, с флагом.

## 9. Доступность

- Каждый интерактивный элемент имеет подпись для VoiceOver / экранного диктора
  и роль. Состояние подключения объявляется при смене.
- Всё доступно с клавиатуры; фокус виден (кольцо на `hover`-пружине).
- Сочетания: ⌘/Ctrl+, — настройки, ⌘/Ctrl+N — добавить подписку,
  ⌘/Ctrl+R — проверить серверы, ⌘/Ctrl+F — поиск по серверам.
- Размер текста следует системному (Dynamic Type на macOS, масштаб текста на Windows).
- Уважаются «Уменьшить движение», «Снизить прозрачность», «Повысить контраст».

## 10. Проверка экрана

Перед тем как назвать экран готовым:

- [ ] Понятно ли за 3 секунды, что здесь главное и что нажать?
- [ ] Видно ли состояние словом, значком и цветом?
- [ ] Есть ли выход из каждого состояния, включая ошибки и пустые списки?
- [ ] Нет ли технических слов вне раздела «Протоколы»?
- [ ] Все цвета, размеры, пружины — из токенов?
- [ ] Каждое движение — пружина или инерция; прерывание продолжает движение?
- [ ] Отпускание после броска учитывает скорость?
- [ ] Светлая и тёмная темы; «Уменьшить движение»; «Снизить прозрачность»?
- [ ] VoiceOver / экранный диктор читает всё осмысленно; работает клавиатура?
- [ ] Минимальный размер окна 940×600 — ничего не обрезано и не наезжает?
- [ ] Скриншоты обеих тем приложены к PR.

## 11. Куда развиваем дизайн

Текущий дизайн — основа, его улучшаем после паритета. Кандидаты:

- Основной островок как контент без стекла: планета на всю площадь, стекло
  только у бокового островка и плавающих элементов (ближе к модели слоёв macOS 26).
- Морфинг кнопки подключения в плашку статуса через `glassEffectID`.
- Добавление подписки одним действием: вставил ссылку в любом месте окна —
  Gorion понял и предложил добавить.
- Упрощённая маршрутизация: готовые сценарии («Российские сайты напрямую»)
  вместо ручных geosite/geoip.

Каждое изменение отсюда — сначала строка `Δ` в parity.md и правка этого файла,
потом код.
